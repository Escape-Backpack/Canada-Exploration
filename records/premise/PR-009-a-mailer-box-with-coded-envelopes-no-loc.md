**Decided 2026-10-22 (designer): no locks, like Norse.** Canada follows the format every adventure moved to on 2026-10-12 (see backpack-kit `GUIDE.md`, "Envelopes and the cipher" and "Packaging"; Norse's PR-007 is the worked example).

- **No padlocks, pouches or pockets.** Each puzzle answer is a code; the cipher turns it into symbols, and the envelope marked with those symbols is the one to open.
- **Codes are 4-5 characters** the cipher can encode, and every envelope code is unique (the kit's `check` enforces both). Example: PZ-009's answer 7329.
- **Box and envelopes** follow the kit's shared packaging: an art-printed mailer box, string-and-button kraft envelopes in two sizes, decoy envelopes so size and count give nothing away.
- **Structure kept from PR-003:** one stop per province and territory (13) plus two final puzzles, each stop a different puzzle type. Each former lock becomes one coded envelope.

**What this supersedes:** PR-003's 15 locks and Q-001's lock types and weights. Q-002 is answered. Older text in those records describes the lock version and is marked so.

**Still open:** the parents' backpack as the story object versus the box (PR-005, Q-007); the cipher's own look (backpack.json still uses the kit's placeholder `shapes`, Q-007); how many envelopes of each size and how many decoys; which props go loose in the box at the start.
